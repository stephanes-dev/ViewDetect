Utilizes a modular, high-performance framework with dynamic auto-scaling and load balancing for efficient real-time data processing.

## Installation

1. Clone the repository: `git clone https://github.com/yhonaach/ViewDetect.git`
2. `cd ViewDetect`
3. Install in editable mode: `pip install -e .`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
